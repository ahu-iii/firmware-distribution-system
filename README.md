# 工业固件安全升级分发系统

网络安全实践项目第 3 题：服务端向工厂各地的嵌入式设备（客户端）安全分发固件更新包。

- 架构：C/S（分发服务端 + 设备客户端 + 离线签名工具）
- 技术栈：C++17 / CMake / Qt 6 / OpenSSL 3 / SQLite
- 核心安全机制：RSA-3072-PSS 固件签名、逐片 SHA-256、防降级、双向认证握手（X25519 + 签名）、AES-256-GCM 会话加密与防重放、A/B 分区回滚、审计哈希链
