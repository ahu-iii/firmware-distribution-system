# 工业固件安全升级分发系统 —— 自查表

| 项 | 内容 |
|---|---|
| 文档版本 | v0.2（底稿；按任务书核对十五类的构成） |
| 依据 | 《项目落地要求任务书》第五章自查表模板；检查项编号同任务书 |
| 项目类型 | 指令控制类（向设备推送固件属于下发控制指令） |

**填写说明**

- 结论只能填“通过”“未过”“不适用”。系统尚未实现，凡需要实测的项目前填“待测”，这不是合法的最终结论，测试阶段必须逐项改掉，提交版不得保留；
- “不适用”已写明理由，可直接沿用；
- “证据文件”是计划采集的文件名，位于 `evidence/`，命名规则见[测试报告](测试验证报告.md)第 2 节；提交前按实际文件名核对；
- 红线结论只能填“通过”或“未过”，不能填“不适用”（任务书第三章第一类）；
- 检查项范围见下面的“十五类的构成”，第 1 ~ 3 节已全部覆盖，没有待补的类别。

**十五类的构成**

任务书第三章“十五类具体要求”的第一类是“安全红线”，即第二章的 8 条一票否决红线（1-1 ~ 1-8），每条红线算一类；其余是第二 ~ 第八类，共 7 类。8 + 7 = 15。

| 类别 | 内容 | 本表位置 |
|---|---|---|
| 第一类（8 条红线） | 1-1 指令明文、1-2 口令存储、1-3 密钥进仓库、1-4 无认证加密、1-5 断网只存内存、1-6 扰扫描周期、1-7 未脱敏数据、1-8 无回滚方案 | 第 1 节 |
| 第二类 | 现场约束与威胁建模（六份基线材料） | 第 2 节 2-① ~ 2-⑥ |
| 第三类 | 架构与部署 | 第 2 节 3-1 ~ 3-3 |
| 第四类 | 通信安全（权重最高） | 第 2 节 4-1 ~ 4-7 |
| 第五类 | 身份授权与密钥 | 第 2 节 5-1 ~ 5-4 |
| 第六类 | 数据闭环 | 第 2 节 6-1 ~ 6-3 |
| 第七类 | 工业现场硬约束 | 第 2 节 7-1 ~ 7-6 |
| 第八类 | 可靠运维 | 第 2 节 8-1 ~ 8-6 |

此外还有任务书第四章的项目类型附加要求（第 3 节）和题目、课程基础要求（第 4 节）。

任务书里另有几处编号与正文对不上，按内容对应如下：

- 第七条红线和第十条常见错误引用的 11-3（脱敏），正文没有第 11 类，对应本表 1-7 和 4-7；
- 附加要求的 10-2 ~ 10-6 是任务书原有编号，本表沿用；
- 第五章写“覆盖第六章十五类、第四章红线、第七章附加要求与第八章合规项”，章号与任务书实际章节不一致，按内容对应为第三章十五类、第二章红线、第四章附加要求；“合规项”正文没有单列，第 4 节的题目与课程基础要求一并自查。
